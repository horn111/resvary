# Grant Application Brand Update

## Ready-to-paste comment

**Project name update: arc-nano-kit is now Settlary**

Following the publication of the Arc Brand Guidelines and Partner Toolkit, I proactively renamed **arc-nano-kit** to **Settlary** to establish a clear, independent product identity.

The repository, npm packages, CLI, documentation, demo, and SDK namespaces have been updated. Arc is now referenced only as the underlying infrastructure through wording such as **"built on Arc."**

This is a branding-only change. The project's ownership, open-source license, implementation, grant scope, and milestones remain unchanged. The update was completed proactively before review to keep the project aligned with current ecosystem guidance.

## Short version

Following the publication of the Arc Brand Guidelines and Partner Toolkit, I proactively renamed **arc-nano-kit** to **Settlary**. The new name establishes an independent product identity, while Arc is referenced only as the underlying infrastructure through wording such as **"built on Arc."** The repository, package names, CLI, documentation, demo metadata, and SDK namespaces have been updated. This is a branding-only change; the project's ownership, implementation, grant scope, and milestones remain unchanged.
